# Product Thinking

## Session Flow

Case Open
→ Solo Observation
→ Observation Review
→ Problem Framing
→ Challenge
→ Solution Space
→ Decision
→ Retro

## Rules

1. No Homework
2. One Problem per Session
3. Think Alone Before Thinking Together
4. Observed ≠ Inferred
5. Challenge Ideas, Not People
6. No Solution Jumping
7. Unknown is a Valid Answer
8. Finish within 2 Hours
9. Questions > Answers
